★★★[9M]

Definition

JavaScript (JS) is a lightweight, interpreted, object-based scripting language used to make web pages interactive. It runs client-side in browsers without server involvement and is one of the three core web technologies alongside HTML and CSS.

💡 JavaScript was created by Brendan Eich in 1995 at Netscape in just 10 days. Originally called "LiveScript".

Arrays in JavaScript

An array is an ordered collection of values accessed by numeric indices (0-based). Arrays in JS are dynamic — size changes automatically.

Creating Arrays — 3 Methods

// Method 1: Array Literal (Recommended)
let fruits = ["Apple", "Banana", "Mango"];

// Method 2: Array Constructor

// Method 3: Empty + push
let colors = [];

Reading Array Elements

let marks = [85, 92, 78, 95];

// By index
console.log(marks[0]);         // 85
console.log(marks[marks.length-1]); // 95 (last element)

// Using for loop
for (let i = 0; i < marks.length; i++) {
    document.write(marks[i] + " ");
}

// Using for...of (ES6) — cleaner
for (let m of marks) {
    console.log(m);
}

// Using forEach with arrow function
marks.forEach((val, idx) => {
    console.log(`Index ${idx}: ${val}`);
});

Q2a — DOM Levels & Document Object Model

★★★[9M]

Definition

The Document Object Model (DOM) is a W3C standard programming interface for HTML/XML documents. It represents the entire web page as a hierarchical tree of nodes that can be accessed, manipulated, and modified using JavaScript.

💡 DOM = Structural Representation + Programming Interface. Every HTML element, attribute, and text becomes a "node" in the DOM tree.

Q2b — jQuery Events

★★[8M]

Definition

jQuery is a fast, lightweight JavaScript library that simplifies HTML DOM manipulation, event handling, AJAX, and animations. Core syntax: $(selector).action()

jQuery Event Categories

// Document Ready — ensures DOM is loaded
$(document).ready(function() {

  // 1. Click event
  $("#btn").click(function() {
    $("p").hide(500); // fade out 500ms
  });

  // 2. Double-click
  $("#box").dblclick(function() {
    $(this).css("background", "gold");
  });

  // 3. Hover (enter + leave)
  $("h2").hover(
    function() { $(this).css("color", "blue"); },
    function() { $(this).css("color", "black"); }
  );

  // 4. Keypress
  $("input").keypress(function(e) {
    console.log("ASCII: " + e.which);
  });

  // 5. on() — preferred method (also works for dynamic elements)
  $("#myBtn").on("click", function() {
    $("#result").text("Clicked!");
  });

  // 6. off() — remove handler
  $("#myBtn").off("click");

  // 7. Submit event
  $("form").on("submit", function(e) {
    e.preventDefault(); // prevent page reload
    alert("Form submitted!");
  });

  // 8. Select, Append, Remove
  $("ul").append("<li>New Item</li>");   // add to end
  $("li:first").remove();                   // remove first li
  $("#myList li").css("color", "green");   // select all li inside #myList
});
jQuery Basics: $() selects, .on() binds, .off() removes, .trigger() fires, .preventDefault() blocks default

JSP Lifecycle

  • Translation: Container converts .jsp → .java (Servlet class)
  • Compilation: javac compiles .java → .class bytecode
  • ClassLoading: JVM ClassLoader loads .class into memory

  • _jspService(): Called per request; handles req/res
  • jspDestroy(): Called once before undeployment; cleanup
Lifecycle: TC-CL-I-S-D — Translate · Compile · ClassLoad · Init · Service · Destroy

Extra — Servlet Lifecycle + doGet vs doPost

★★[8–9M]

Servlet Definition

A Servlet is a Java class that extends HttpServlet and runs on a web server to handle HTTP requests and generate responses. It is the foundation for JSP and frameworks like Struts.

Servlet Lifecycle

  • Loading & Instantiation: ClassLoader loads servlet class; container creates one instance.
  • init(): Called once — initialize resources (DB connections, config).
  • service(): Called per request — dispatches to doGet() or doPost().
  • destroy(): Called once on undeploy — release resources.

doGet() vs doPost()

FeaturedoGet()doPost()
HTTP MethodGETPOST
Data locationURL query string: ?name=valRequest body (hidden)
Data limit~2048 chars (URL limit)No practical limit
SecurityLess secure — visible in URL, browser history, logsMore secure — body not logged by default
IdempotentYes — safe to repeat, bookmarkNo — may cause side effects
CachingCan be cached by browser/proxyNot cached
BookmarkableYesNo
Use CaseRead/search operationsForm submission, file upload, login
import javax.servlet.*;
import javax.servlet.http.*;
import java.io.*;

public class LoginServlet extends HttpServlet {
    public void init() { System.out.println("Init called once"); }

    protected void doGet(HttpServletRequest req, HttpServletResponse res)
            throws IOException {
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        String name = req.getParameter("name"); // from URL
        out.println("<h2>Hello, " + name + "!</h2>");
    }

    protected void doPost(HttpServletRequest req, HttpServletResponse res)
            throws IOException {
        req.setCharacterEncoding("UTF-8");
        String user = req.getParameter("username"); // from body
        String pass = req.getParameter("password");
        if (user.equals("admin") && pass.equals("1234")) {
            res.sendRedirect("dashboard.jsp");
        } else {
            res.sendRedirect("login.jsp?error=1");
        }
    }
    public void destroy() { System.out.println("Destroy called"); }
}

Q5a — Sessions & Cookies in PHP

★★★[9M]

Why Session Management?

HTTP is stateless — each request is independent. Sessions and cookies maintain state across multiple requests from the same user.

1. PHP Cookies

// Set cookie: name, value, expiry, path, domain, secure, httponly
setcookie("username", "Alice", time()+3600, "/"); // 1 hour
setcookie("theme", "dark", time()+86400*30);    // 30 days

// Read cookie
if (isset($_COOKIE["username"])) {
    echo "Welcome, " . htmlspecialchars($_COOKIE["username"]);
} else {
    echo "New visitor";
}

// Delete cookie — set expiry in past
setcookie("username", "", time()-3600, "/");

2. PHP Sessions

// MUST call session_start() before any output
session_start();

// Set session variables
$_SESSION["user"]  = "Alice";
$_SESSION["role"]  = "admin";
$_SESSION["login_time"] = time();

// Read session
echo "Hello " . $_SESSION["user"];
echo "Role: " . $_SESSION["role"];

// Check if logged in
if (!isset($_SESSION["user"])) {
    header("Location: login.php");
    exit();
}

// Remove one variable
unset($_SESSION["role"]);

// Destroy entire session (logout)
session_unset();
session_destroy();
FeatureCookieSession
StorageClient browserServer (/tmp/sess_* file)
SecurityLess — user can editMore — user cannot access data
Size limit~4 KB per cookieNo practical limit
ExpirySet manually with time()Browser close or session_destroy()
Data typesStrings onlyAny PHP type (array, object)
Access$_COOKIE["key"]$_SESSION["key"]
PerformanceStored client-sideServer I/O for each request
Cookie = Client keeps data. Session = Server keeps data, sends only an ID.
session_start() must be FIRST line before any HTML output. setcookie() also must be before output. Both use HTTP headers.

★★★[9M]

Definition

An associative array in PHP is an array where each element is stored as a key → value pair, and the key is a meaningful string (not a numeric index).

    "name"  => "Alice",
    "age"   => 22,
    "grade" => "A",

Q6b — AJAX: Purpose & Example

★★★[9M]

Definition

AJAX (Asynchronous JavaScript and XML) is a web development technique that allows a webpage to communicate with a server and update parts of the page without reloading the entire page.

💡 AJAX is not a language — it's a technique combining: JavaScript + XMLHttpRequest/fetch + JSON/XML + DOM manipulation.

AJAX Architecture

Method 1: XMLHttpRequest (Traditional)

// Step 1: Create XHR object
let xhr = new XMLHttpRequest();

// Step 2: Configure request
xhr.open("GET", "data.php?id=5", true); // true = async

// Step 3: Handle response
xhr.onreadystatechange = function() {
    if (xhr.readyState === 4 && xhr.status === 200) {
        let data = JSON.parse(xhr.responseText);
        document.getElementById("result").innerHTML =
            "Name: " + data.name + " Marks: " + data.marks;
    }
};

// Step 4: Send request
xhr.send();

Method 2: Fetch API (Modern — ES6)

fetch("data.php")
  .then(res => res.json())       // parse JSON
  .then(data => {
      document.getElementById("name").textContent = data.name;
      document.getElementById("marks").textContent = data.marks;
  })
  .catch(err => console.error("Error:", err));

// POST request with fetch
fetch("save.php", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name: "Alice", marks: 95 })
}).then(res => res.text()).then(console.log);

Server-side: data.php

<?php
header("Content-Type: application/json");
header("Access-Control-Allow-Origin: *");
$data = ["name" => "Alice", "marks" => 95];
echo json_encode($data);
?>
readyStateMeaning
0UNSENT — open() not called yet
1OPENED — open() called
2HEADERS_RECEIVED — headers available
3LOADING — response downloading
4DONE — response complete ✓
AJAX = Asynchronous JavaScript And XML. Modern apps use JSON not XML. Check: readyState==4 AND status==200.

Callback methods are lifecycle methods called by the EJB container at specific lifecycle events. The developer overrides them.

Session Bean Callbacks

MethodWhen CalledPurpose
setSessionContext(ctx)After instantiationStore context reference
ejbCreate()Client calls create()Initialize bean
ejbRemove()Client calls remove()Cleanup before removal

Entity Bean Callbacks

MethodWhen Called
ejbCreate()New record being inserted into DB

ejbPassivate()Entity returned to pool
public class CartBean implements SessionBean {
    private SessionContext ctx;
    private ArrayList cart = new ArrayList();

    public void setSessionContext(SessionContext c) { ctx = c; }
    public void ejbCreate()   { cart.clear(); }
    public void ejbRemove()  { cart = null; }
    public void ejbActivate() { /* restore resources */ }
    public void ejbPassivate(){ /* release resources */ }

    // Business method
    public void addItem(String item) { cart.add(item); }
    public ArrayList getCart() { return cart; }
}

Q8b — EJB Types & When to Use Session Beans

★★★[9M]

Types of EJB

1. Stateless Session Bean

  • No conversational state between calls.
  • Container pools instances — reused across clients.
  • Fast and scalable. Annotated: @Stateless
  • Example: Tax calculator, authentication service, email sender.

2. Stateful Session Bean

  • Maintains state across multiple calls for one client.
  • One instance per client session. Annotated: @Stateful
  • Example: Shopping cart, multi-step form wizard, bank transfer workflow.

3. Singleton Session Bean (EJB 3.1+)

  • One instance per application, shared by all clients.
  • Annotated: @Singleton
  • Example: App configuration, global counter, cache manager.

4. Entity Bean (Legacy — replaced by JPA)

  • BMP (Bean-Managed): developer writes JDBC code manually.
  • CMP (Container-Managed): container auto-generates DB access.
  • EJB 3+ replaced with @Entity JPA annotations.

5. Message-Driven Bean (MDB)

  • Asynchronous; listens for JMS (Java Message Service) messages.
  • Implements MessageListener interface. Annotated: @MessageDriven
  • Example: Order processing queue, email notification system.

When to Use Session Beans

SituationBean TypeReason
Calculate tax / currency conversion@StatelessNo user state; poolable, fast
User login / authentication@StatelessSingle-step, independent operation
Send email/SMS notifications@StatelessFire-and-forget, no session needed
Shopping cart (multi-request)@StatefulMust remember items per user
Multi-step form wizard@StatefulNeeds intermediate state across steps
Online banking transfer (3 steps)@StatefulMust track account, amount, confirm
Application configuration/settings@SingletonShared globally, one instance
Application startup initialization@Singleton + @StartupRuns once at app deployment
Async order processing queue@MessageDrivenDecoupled from client, JMS-based
// EJB 3.x Annotations (modern style)

// Stateless Session Bean
@Stateless
public class TaxBean {
    public double calculate(double amount) {
        return amount * 0.18; // 18% GST
    }
}

// Stateful Session Bean
@Stateful
public class CartBean {
    private List<String> items = new ArrayList<>();
    public void add(String item) { items.add(item); }
    public List<String> getItems() { return items; }
    @Remove
    public void checkout() { items.clear(); }
}

// Singleton Session Bean
@Singleton @Startup
public class AppConfigBean {
    @PostConstruct
    public void init() { System.out.println("App started"); }
    public String getVersion() { return "2.0"; }
}
